# Does a long pipe run slow the flow?
board: Fluids   date: Y153-06-27   author: pipefitter_uri   status: open

- pipefitter_uri | Y153-06-27 | Asked twice this week: does a long run of pipe slow the water down? No. A pipe moves fluid at the same rate however long it is. What a long run does is hold more, and holding more is not the same as flowing slower.
  - table_herr | Y153-06-27 | A pipe tile holds twenty. A run of thirty tiles holds six hundred, and the first water you put in has to fill it before anything arrives at the far end. That is a delay, not a rate.
    - pipefitter_uri | Y153-06-27 | A delay you pay once and then forget, unless you drain it.
  - throughput_tony | Y153-06-28 | And a full run is a buffer, which is why the long runs in our plant have never been the problem. The problem is always a run that is nearly empty.
    - pipefitter_uri | Y153-06-28 | A run that is nearly empty is a run with a pump too small at one end or a machine drinking too fast at the other.
  - slow_steam | Y153-06-28 | One boiler takes ten water a second. One pump gives twenty. So one pump feeds two boilers exactly, and exactly is the number that wakes me up.
    - pipefitter_uri | Y153-06-29 | Exactly is the number that wakes everybody up. Put the advanced pump in and stop waking up.
  - half_belt_hana | Y153-07-02 | We ran a pipe two floors down and it took a shift to fill. Nobody had told the afternoon shift, so they spent the afternoon looking for a blockage that was a pipe filling.
