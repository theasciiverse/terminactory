# How many solar panels does a welder need?
board: Power   date: Y140-02-08   author: green_helmet   status: solved

- green_helmet | Y140-02-08 | I have four cheap panels on the roof and a welder on the floor below. The welder runs, then stops, then runs. Nothing else is on that grid.
  - ivo_p | Y140-02-08 | Four cheap panels give forty EC. A welder draws only while it works, and it works in bursts, so it pulls the grid down at the start of every burst. You are seeing the sag, not a fault.
    - slow_steam | Y140-02-08 | Size the grid for the busy minute. Forty EC is a quiet minute.
      - green_helmet | Y140-02-09 | How many for a busy minute?
        - ivo_p | Y140-02-09 | Two more panels and a pole between the welder and the panels. The pole is not optional. Panels reach four tiles and a pole reaches three from where it stands.
          - green_helmet | Y140-02-09 | Two more panels and a pole. It has run all morning. Thank you. Edit: solved.
            - ivo_p | Y140-02-10 | Good. Now put a pole near the next machine before you build it, not after.
