# Engine block

**Engine block** is a large machine part made from a frame, pistons, a gearbox and a boiler shell.

The [[large-basic-assembler|large basic assembler]] builds an engine block from a [[frame]], [[piston|pistons]], a [[gearbox]] and a [[boiler-shell|boiler shell]]. Engine blocks are used only by the [[steam-tractor]], so they make a clear goal for a line of parts.

## Tips
- Engine blocks take a lot of pistons. Make sure the piston line is in place before you start the engine block.
- Think of the engine block as the middle of a long chain. It helps to keep its inputs on tidy belts.
