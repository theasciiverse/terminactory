# Fast belt

**Fast belt** is a belt that moves items much quicker than the basic belt. It is the one to use once a single belt cannot keep up with a busy line.

It takes the same items in and sends them out the front, as the basic belt does. The gain is in how much it carries, so a single fast belt can serve a machine block that would overload a basic belt. It costs more, and it needs a gearbox before it can be unlocked. Fast belts are available by research once the gearbox is in hand.

## Tips
- Upgrade only the stretches that choke. The rest can stay on basic belt.
- Use the upgrade planner to swap a whole run of basic belts for fast ones in one go.
- A fast belt feeding a slow machine just backs up, so match the belt to the machine.

## Placement
- A single tile, turned to face the way the items should travel.
