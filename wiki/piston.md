# Piston

**Piston** is a moving part made from a steel rod, a hardened iron plate and screws.

The [[basic-assembler|basic assembler]] makes a piston from a [[steel-rod|steel rod]], a [[hardened-iron-plate|hardened iron plate]] and [[screw|screws]]. Pistons are used in the [[engine-block]] and nowhere else, so a piston line only needs to keep one machine happy.

## Tips
- A piston needs hardened iron plate, so that line has to be running before the pistons can be made.
- The engine block takes several pistons, so the piston line matters more than its size suggests.
