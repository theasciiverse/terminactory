# Belt tunnel

**Belt tunnel** lets a belt dive under other things, so it can cross a machine or a row of belts. Place an entrance, then an exit further along the same line, and anything can be built in between.

The entrance takes items in and carries them under, and the exit brings them back up in front of it. The tunnel only reaches a short way, so the exit has to sit within that reach. Items keep their spacing as they travel underneath. With no exit ahead, the entrance simply waits, so always build the exit before you expect items to flow.

## Tips
- Place the entrance first, then walk to the other side and place the exit facing the same way.
- Use tunnels to cross a busy line without taking it apart.
- If nothing comes out, check that the exit is facing the same direction as the entrance.

## Placement
- A single tile, turned to face the way the belt runs. The exit sits in line, ahead of the entrance.
