# Waste

**Waste** is the unwanted leftover of several dirty recipes. It has no use except as fuel, and it costs money to get rid of.

Blast furnaces, coke ovens, kilns and some etchant and silicon recipes all make waste. It always leaves a machine out the back, never the front. A machine whose back has nowhere to put waste fills up, stops, and says so. A [[boiler]] will burn waste as fuel, so it can keep [[power]] going when [[coal]] runs short. A [[trade-post|trade post]] set to sell for money will take it, for a small fee. Research and split posts refuse it. Removing a part that still holds waste costs the same fee, and the game asks first when a removal would be expensive.

## Tips
- Put a belt, crate or trade post behind every machine that makes waste, or the line will back up.
- Waste can fuel a boiler, which saves coal.
- [[silicon-scrap|Silicon scrap]] is not waste: it sells and can be melted again.
