# Relay

**Relay** is a switch built from a copper coil, a spring and an iron sheet.

The [[crude-assembler|crude assembler]] builds a relay from a [[copper-coil|copper coil]], a [[spring]] and an [[iron-sheet|iron sheet]]. Relays are one of the parts a [[control-board|control board]] is built from.

## Tips
- A relay needs several different parts, so it is a good place to see which input is running late.
- If control boards are scarce, check the relay line before blaming the advanced assembler.
