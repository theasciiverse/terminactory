# Spring

**Spring** is wound from [[iron-rod]] in a winder. Springs go into [[gauge]]s, [[relay]]s and [[keyboard]]s.

Winders make springs as well as coils, so a winder can serve both lines.

## Tips
- Springs are needed for gauges and relays, so keep the winder fed with rods.
- Keyboards take several springs, so they need a steady supply.
- The winder also makes coils, so a single winder can cover both jobs if it is not busy.
