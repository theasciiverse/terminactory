# Screw

**Screw** is turned from [[iron-rod]] in a lathe. Screws go into [[piston]]s and [[frame]]s.

A lathe makes several screws from each rod, so screws are cheap to make in bulk. Frames use a lot of them.

## Tips
- Frames need many screws, so keep a screw line running when building them.
- Screws are small parts that stack up fast in a frame line.
