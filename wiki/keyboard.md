# Keyboard

**Keyboard** is a set of keys made from springs, a circuit board and an iron sheet.

The [[crude-assembler|crude assembler]] builds a keyboard from [[spring|springs]], a [[circuit-board|circuit board]] and an [[iron-sheet|iron sheet]]. Keyboards go into the [[terminal]], which needs one alongside a lamp matrix and a tube board.

## Tips
- Springs are the bulk of a keyboard, so feed that line first.
- The keyboard is made in the crude assembler, so it is a good first meeting between the crude and advanced lines.
