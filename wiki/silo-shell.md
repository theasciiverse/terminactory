# Silo shell

**Silo shell** is a large steel casing made from steel sheets and a valve.

The [[welder]] builds a silo shell from [[steel-sheet|steel sheets]] and a [[valve]]. Silo shells are needed by the [[pump-unit]], which is the only machine that uses them, so the silo shell is a stop on the way to a bigger part.

## Tips
- A silo shell takes a lot of steel sheet. Plan the steel line before you plan the welder.
- The valve and the steel sheet come from different lines, so give each its own path to the welder.
