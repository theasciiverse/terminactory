# Filtering arm

**Filtering arm** is a mechanical arm that picks items up from the tile behind it and drops them on the tile in front. It can be set to move only one kind of item.

It picks from belts, drill outputs, crates, splitters, and the outboxes of machines and elevators. Its filter is set with the set-up key, and middle-clicking an arm copies its setting to the next one you place. With no filter it takes whatever is behind it. Its reach is a single tile, so the long arm is the one to use when something sits in between.

## Tips
- Set a filter when you only want one item to cross, so the rest keeps flowing past.
- Place it so the tile behind is the source and the tile in front is the one that takes the items.
- Arms take power to run, so keep a pole in range of them.

## Placement
- A single tile, with a front that turns to face any way. It takes from behind and drops ahead.
