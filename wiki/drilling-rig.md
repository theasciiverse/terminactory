# Drilling rig

**Drilling rig** is built by a large advanced assembler from [[steel-girder]]s, [[gearbox]]es, [[reinforced-concrete]], an [[electric-motor]] and a [[pump-unit|pump unit]].

No recipe in the game takes a drilling rig as an input, so it is an end product.

## Tips
- Build the parts ahead of time, because the rig takes a long time to assemble.
- The large advanced assembler is the only machine that makes rigs.
- Keep reinforced concrete flowing, since the rig takes a lot of it.
