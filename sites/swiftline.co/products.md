# Swiftline Conveyors: Products

**Fast belt.** Takes the same items as a basic belt and sends them out the front, but moves them much quicker. It costs more, and it needs a gearbox before it can be unlocked. Use the upgrade planner to swap a whole run in one go. A fast belt feeding a slow machine just backs up, so match the belt to the machine.

**Basic assembler.** A small square assembler that runs the crude recipes much faster. It builds electric motors, pistons, terminals and disk drives. A motor needs copper coil, a steel rod and bearings, so plan those lines first. Runs on EC. Motors open the advanced drill and the large basic assembler at [[ampleworth.co/|Ampleworth]], so this machine is a turning point.

**Upgrade planner.** Swaps the parts in a marked area for their next version, every belt, drill, panel and assembler in it. You pay only the difference in price. If you want to keep the layout first, [[brannock.co/|Brannock's]] blueprints can copy it.
