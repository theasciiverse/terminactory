# Essay — The same screen (Y158-11-08)

The night shift is quiet. The Gearwright line is patient. Valves, gauges, lamps, relays, gearboxes, ten seconds each. I do not program them. I only watch the terminal.

I have written down what the terminal shows for eight years. It does not change. The same lamps, the same order, the same quiet. People ask me why I bother writing it down if it never changes. I bother because one day it might, and I want to be the one who noticed first.
