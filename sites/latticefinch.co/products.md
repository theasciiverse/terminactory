# Lattice & Finch: Products

**Advanced assembler.** A square machine that builds control boards much faster than the crude assembler does by hand. It then builds tube boards, circuit boards, transistors, transistor boards and masks, and it runs everything below it faster. Once you have it, the hand-wired recipe is hidden, so this is the one to use.

**Precision assembler.** A square machine for the fine work: microprocessors, RAM chips and mainboards, and control boards faster than the advanced assembler does. It needs a lot of EC. It does nothing for the basic goods, so keep a basic assembler running beside it.

**Etcher.** A square machine on EC. It takes a doped wafer, a mask and etchant, and cuts out dies. Each wafer also leaves scrap. The scrap sells, and it can be melted again.

**Large advanced assembler.** A large square machine for the biggest goods: generators, control panels, drilling rigs and steam tractors. It also speeds up the large basic goods. Build a drilling rig's parts first, and give each one its own belt.

**Large advanced drill.** A large square drill on EC that mines much faster than an advanced drill. Put a fast belt along its front edge to carry all of it.
