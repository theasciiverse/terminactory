# Bulletin MLI-Y138-02 — Waste return reminders

**Issued:** Y138-02-20 **Effective:** Y138-02-20 **Deadline:** none **Reference:** MLI-B-138-02

Monthly waste returns are now due on the last day of the following month. Plants that miss a return will receive a reminder each month until it is filed.

Clause 1 — The first reminder is issued with this bulletin.

Clause 2 — This is the first annual reminder; it is repeated each year until the return is filed.
