# Bulletin MLI-Y157-11 — Reminder: file the old returns

**Issued:** Y157-11-03 **Effective:** Y157-11-03 **Deadline:** Y157-12-31 **Reference:** MLI-B-157-11

Plants that have not filed the Y156 waste returns on Form MLI-7A must do so by Y157-12-31. Late returns are charged at the standard rate. This reminder is issued annually until the returns are received.

Clause 1 — Plants filing after Y158-05-01 should note that Form MLI-7A is withdrawn; use Form MLI-7 and mark the return period clearly.

Clause 2 — This reminder is issued annually. It was first issued Y138-02-20.

Clause 3 — The standard late fee is one crown per month per missing return, payable to the regional office.
